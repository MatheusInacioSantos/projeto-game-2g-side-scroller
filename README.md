Criação de jogo estilo Mario World

Aula 1

Requisitos iniciais

Sprites:
- Jogador
- Bloco de parede

Regras do jogo
-  O jogador deverá se movimentar através das teclas WASD
-  Será aplicada a lógica de gravidade no jogo
    - Pulo com base no tempo de aperto da tecla SPACE
    - Corrida ao segurar a tecla SHIFT
